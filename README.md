# Mohammad Hossein Fakouri

I am a mechanical engineering researcher working on robotics, control, and simulation. My main interests are model-based robot control, learning-based compensation, trajectory tracking under disturbances and uncertainty, and reproducible evaluation of robotic systems.

My M.Sc. research focused on combining computed torque control with bounded residual deep reinforcement learning for a simulation-based cable-driven lower-limb rehabilitation robot.

## Research Interests

- Robot dynamics, modelling, and control
- Model-based and learning-based control
- Trajectory tracking under disturbances and parametric uncertainty
- Cable-driven and rehabilitation robots
- Mobile robot planning and risk-aware navigation
- ROS 2 robotics workflows
- Simulation-based validation and numerical analysis

## Selected Projects

### [ROS 2 Planar Robot Trajectory Tracking](https://github.com/mhfakouri/ROS-simple-project)

A ROS 2 Python package for trajectory replay, feedback control, simulated 2-DOF robot dynamics, disturbance injection, rosbag logging, and tracking-error analysis.

### [Mobile Robot Navigation](https://github.com/mhfakouri/mobile-robot-navigation-basics)

A Python project combining terrain-cost modelling, A* planning, risk-aware path selection, waypoint tracking, disturbances, and quantitative performance metrics.

### [Tactile and Force Contact Detection](https://github.com/mhfakouri/tactile_force_contact_detection)

A signal-processing pipeline for filtering synthetic force/torque measurements, detecting contact events, and extracting contact-related features.
