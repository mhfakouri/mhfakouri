# Mohammad Hossein Fakouri

I am a mechanical engineering graduate interested in robotics, control, and simulation. My work focuses on robot modelling, trajectory tracking, control under uncertainty, and learning-based compensation methods.

My M.Sc. research explored the combination of computed torque control and residual deep reinforcement learning for a simulation-based cable-driven lower-limb rehabilitation robot.

## Areas of Interest

* Robot dynamics and control
* Model-based and learning-based control
* Trajectory tracking under disturbances and uncertainty
* Cable-driven and rehabilitation robots
* Mobile robot planning and navigation
* ROS 2 robotics workflows
* Simulation and numerical analysis

## Selected Projects

### [ROS 2 Planar Robot Trajectory Tracking](https://github.com/mhfakouri/ROS-simple-project)

A ROS 2 Python project for trajectory replay, feedback control, simulated 2-DOF robot dynamics, disturbance injection, rosbag logging, and tracking-error analysis.

### [Mobile Robot Navigation Basics](https://github.com/mhfakouri/mobile-robot-navigation-basics)

A Python project combining terrain-cost modelling, A* planning, risk-aware path selection, waypoint tracking, disturbances, and quantitative performance metrics.

### [Tactile and Force Contact Detection](https://github.com/mhfakouri/tactile_force_contact_detection)

A signal-processing project for filtering synthetic force and torque measurements, detecting contact events, and extracting contact-related features.
